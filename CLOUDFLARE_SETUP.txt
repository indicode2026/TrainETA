USER FLOW
1. No browser location permission is requested.
2. Railway station directory loads from RailRadar through Cloudflare.
3. User can search by station name, city, or code.
4. User selects a station.
5. User enters a 5-digit train number.
6. Live train status and ETA are loaded through the Worker.

RAILRADAR LIMITS
Live results depend on RailRadar availability, API quota, and the train's current
telemetry. The app does not invent live values when the upstream service has no data.
